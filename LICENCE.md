## 📖 О ПРОЕКТЕ

### 🎯 Философия проекта
**Majestic RP Fishing Activity Assistant** — это инструмент, созданный для оптимизации повторяющихся игровых процессов. Проект разработан с уважением к игрокам, которые хотят эффективно использовать своё время, автоматизируя рутинные задачи, и при этом оставаться в рамках правил сервера, используя только визуальный анализ экрана.

### 👥 Для кого этот проект
- **Игроки с ограниченным временем** — хотят фармить ресурсы без постоянного присутствия у экрана
- **Фармеры и коллекционеры** — добывают ресурсы для крафта и продажи
- **Новички** — быстро прокачивают навык рыболовства
- **Опытные игроки** — оптимизируют свои игровые процессы
- **Контент-мейкеры** — демонстрируют возможности автоматизации

### 🛡️ Принципы безопасности и этики
1. **Визуальный анализ, не взлом** — ассистент работает только со скриншотами игрового окна, не изменяя память или файлы игры
2. **Имитация действий игрока** — полностью повторяет естественное поведение человека
3. **Прозрачность** — все алгоритмы основаны на обработке изображений (OpenCV) и симуляции нажатий клавиш
4. **Минимальный риск блокировки** — взаимодействие происходит исключительно через игровой интерфейс
5. **Этичное использование** — проект предназначен для личного использования в рамках, разрешённых сервером

### 💡 Что делает этот проект уникальным
- **Комплексный подход** — сочетает макросы и компьютерное зрение для надёжной работы
- **Умное обнаружение** — распознаёт визуальные индикаторы игры (иконки, полосы прогресса)
- **Открытая архитектура** — возможность донастройки под любые разрешения экрана
- **Сообщество** — активная поддержка и обновления
- **Портативность** — работает без установки, достаточно запустить `.exe` файл

### 🚫 Чего здесь НЕТ
- Взлома игровых файлов или памяти
- Изменения сетевого трафика (пакетов игры)
- Внедрения в процесс игры
- Эксплойтов и баг-юза
- Вредоносного кода любого типа

### 🔬 Технические детали
- Реализован с использованием OpenCV для обнаружения визуальных маркеров
- Использует Template Matching для поиска ключевых элементов (поплавок, полоса индикатора)
- Отслеживает движение объектов и определяет направление (влево/вправо)
- Имитирует нажатия клавиш `A`, `D` и `SPACE` в зависимости от поведения объекта
- Автоматически адаптируется к размерам и позиции окна игры
- Требует режима экрана "Оконный без рамки" для корректной работы

## ⚠️ Инструкция по использованию
1. Скачайте скомпилированный `.exe` файл из раздела релизов.
2. Поместите файлы изображений (`splawik.png`, `pasek.png`, `czapka.png`) в одну папку с программой.
3. Запустите **Majestic RP** в режиме "Оконный без рамки".
4. **Купите и наденьте розовую шляпу** — она должна быть видна для корректной работы.
5. Запустите программу от имени администратора (если требуется).
6. Встаньте в зону рыбалки и начните процесс (нажмите `E`).
7. Нажмите `Page Up` для активации бота.
8. Наслаждайтесь автоматической рыбалкой!

> **Важное уведомление:**  
> Данный ассистент работает исключительно через анализ изображения экрана и симуляцию нажатий клавиш. Он не вмешивается в память игры и не модифицирует её файлы, что делает использование максимально безопасным.

## 🛑 Антивирусные предупреждения
Любое ПО, работающее с симуляцией нажатий клавиш, может вызывать ложные срабатывания антивирусов.

**Рекомендации:**
1. Временно отключите защиту в реальном времени при первом запуске.
2. Добавьте папку ассистента в исключения.
3. Используйте только проверенный источник для скачивания.
